# Reglas para Agentes (AGENTS.md)

## Seguridad y Manejo de Secretos
- **PROHIBIDO LEER ARCHIVOS DE SECRETOS**: No debes abrir, leer ni exponer el archivo `.env` ni ningún otro archivo que contenga secretos, tokens o credenciales reales.
- **USO EXCLUSIVO DE `.envmodelo`**: Solo tienes permitido leer, consultar o actualizar la plantilla `.envmodelo` para verificar la estructura y nombres de las variables requeridas por el proyecto.
